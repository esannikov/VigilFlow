# VigilFlow

Інтерактивна схема одного епізоду роботи VIGIL — системи ШІ-агентів, яка перетворює новини на образи. Схема крок за кроком показує, як подія 2 серпня 2026 року стала роботою *The Crossing Leads Back*.

- Українською: https://esannikov.github.io/VigilFlow/
- English: https://esannikov.github.io/VigilFlow/en.html

Кожна сторінка — один автономний файл: зображення, стилі й код вбудовані, з інтернету підвантажуються лише шрифти.
